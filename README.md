# Taktaka — دليل الاستخدام الكامل

برنامج يصدر صوت لوحة مفاتيح وفأرة ميكانيكية عند كل ضغطة، في أي برنامج تعمل عليه. مبني بـ Electron وقاعدة بيانات Realm.

---

## 1. محتويات المجلد

| الملف | وظيفته |
|---|---|
| `main.js` | العملية الرئيسية: النافذة، الصينية (Tray)، التقاط الضغطات العام، قاعدة Realm، نسخ الملفات |
| `preload.js` | الجسر الآمن بين الواجهة والنظام (`window.mvdx`) |
| `index.html` | كل الواجهة والمحرك الصوتي |
| `package.json` | اسم البرنامج والمكتبات وأمر البناء |
| `run.bat` | يثبّت المكتبات ويشغّل البرنامج |
| `build-exe.bat` | يبني ملف EXE محمول داخل مجلد `dist` |
| `assets/tray.png` | أيقونة البرنامج والصينية |
| `README.md` | هذا الملف |

**يجب أن تبقى كلها في مجلد واحد.** المجلد `assets` بجانب `main.js`.

## 2. التشغيل

1. ثبّت Node.js من `nodejs.org` (أو دع `run.bat` يحاول تثبيته بأداة winget).
2. انقر مرتين على `run.bat`. أول مرة تأخذ وقتا لأنه ينزّل المكتبات.
3. لصنع ملف EXE: انقر مرتين على `build-exe.bat`. الناتج داخل مجلد `dist`.

إن كان البرنامج مخفيا بجانب الساعة وشغّلته مرة ثانية، تظهر النافذة المخفية بدل فتح نسخة جديدة.

## 3. أين تُحفظ بياناتك

مجلد بيانات البرنامج (عادة `%APPDATA%\Taktaka`):

- `taktaka.realm` — كل الإعدادات والحزم التي أضفتها.
- `ambiance\` — ملفات الصوت والفيديو التي رفعتها في Mood.
- `images\` — صور الخلفيات.

حذف المجلد يعيد البرنامج كأنه جديد.

## 4. شريط العنوان (أعلى النافذة)

- **اسم `Taktaka` و `v1.0.0`**: نص فقط. اسحب من الشريط لتحريك النافذة.
- **زر `–` (تصغير)**: يصغّر النافذة إلى شريط المهام. البرنامج يعمل.
- **زر العين المشطوبة (إخفاء)**: يخفي النافذة بالكامل ويتركها تعمل بجانب الساعة. تختفي من شريط المهام. أيقونتها قد تكون داخل السهم الصغير `^` بجانب الساعة.
- **زر `✕` (إغلاق)**: يغلق البرنامج كله. تتوقف الأصوات. لا يذهب للصينية.

### تحريك النافذة وتغيير حجمها
- **التحريك**: اسحب من شريط العنوان، أو من **الحافة الجانبية الرفيعة** (شريط بعرض 8 بكسل على يمين النافذة ويسارها). الضغط فيهما لا يضغط أي زر.
- **تكبير الشاشة كاملة**: انقر مرتين متتاليتين على شريط العنوان أو على الحافة الجانبية الرفيعة. مرتان ثانية تعيد الحجم.
- **التكبير والتصغير**: اسحب **المثلث الصغير في الزاوية السفلية اليمنى** (مؤشر الفأرة يتحول إلى سهم قطري). الحد الأدنى 420×520. أو اسحب حافة النافذة نفسها.
- **حجمك يُحفظ** ويُسترجع عند التشغيل القادم.
- **شريط التمرير مخفي** لحفظ الشكل. استخدم عجلة الفأرة للتمرير.
- **أثر الضغط على المربع العلوي**: يعمل مع أزرار لوحة المفاتيح فقط. الفأرة لا تضغطه إلا إن نقرت عليه أنت.

## 5. الصينية (بجانب الساعة)

- **نقرة يسار على الأيقونة**: تُظهر النافذة وتضعها في المقدمة.
- **نقرة يمين تفتح قائمة**:
  - `Show`: تُظهر النافذة.
  - `Mute / Unmute`: تكتم كل الأصوات أو تعيدها.
  - `Quit`: تغلق البرنامج.

## 7. الشريط السفلي (التنقل)

خمسة أزرار. النقر على أي منها يفتح صفحته. الصفحة الحالية تتلوّن بلون التمييز:

`Home` · `Sound packs` · `Customize` · `Mood` · `Settings`

فوقه سطر صغير: `Latency ≈ X ms · 32-voice pool`.

- `Latency` متوسط آخر 20 ضغطة: زمن المعالجة + تأخير جهاز الصوت نفسه. الجزء الأكبر منه من الجهاز. السماعات اللاسلكية ترفعه.
- `32-voice pool`: أقصى 32 صوتا في اللحظة نفسها. عند الزيادة يخفت الأقدم في 40 ميلي ثانية بدل أن يُقطع.

## 8. صفحة Home

### المربع الكبير في الأعلى
- يعرض اسم البرنامج `Taktaka`. لا يُنقر ولا يمكن تغيير محتواه.
- **عند الضغط على أي زر في لوحة المفاتيح**: ينضغط المربع للأسفل ويتوهج، ثم يعود عند رفع اليد. يعمل حتى لو كنت في برنامج آخر. النقر بالفأرة عليه نفسه يضغطه أيضا.

### قسم `Keyboard`
- **زر `⇄` (خلط)**: يختار حزمة لوحة مفاتيح عشوائية.
- **بطاقة الحزمة** (اسم الحزمة + المؤلف): النقر عليها يفتح قائمة منسدلة بكل حزم لوحة المفاتيح. انقر اسما ليتفعّل فورا. النقر خارج القائمة يغلقها. تعمل أيضا بمفتاحي `Enter` و `Space` وهي محددة.
- **شريط الصوت (0 إلى 100%، وحتى 200% بعد تفعيل خيار الإعدادات)**: يغير علو صوت لوحة المفاتيح فورا.
  - الرقم أبيض أو رمادي حتى 100%.
  - **فوق 100% يصير الرقم والشريط أصفر**: تضخيم حقيقي للصوت (المضاعِف `×2.00` عند 200%). قد يتشوه الصوت إن كانت الحزمة عالية أصلا.
  - يُحفظ الرقم عند إفلات الشريط، وتُكتب في السجل `gain ×…`.
- **زر السماعة 🔊 / 🔇**: يكتم لوحة المفاتيح وحدها. الفأرة تبقى تعمل. انقر مرة ثانية لإعادته.

### قسم `Mouse`
نفس عناصر Keyboard تماما، لكنها للفأرة: نقرة يسار ويمين ووسط، وعجلة التمرير فوق وتحت.

### `Enable all sounds`
- مفتاح تشغيل وإيقاف شامل. مضاء = كل الأصوات تعمل. مطفأ = كتم كامل (لوحة المفاتيح والفأرة وMood).

### `Sound pack editor` — زر `Open ↗`
- **ينقلك إلى صفحة `Sound packs` فقط.** لا يوجد محرر مدمج لتعديل التوقيتات. لتعديل حزمة عدّل ملف `config.json` بنفسك ثم استوردها.

## 9. صفحة Sound packs

قائمتان: `Keyboard packs` و `Mouse packs`. كل صف: اسم الحزمة + نوعها + مؤلفها + نسختها.

- **زر `Delete`** (يظهر بجانب كل حزمة، حتى المدمجة): تظهر نافذة تحذير.
  - للحزمة التي أضفتها: "This cannot be undone" وتُحذف نهائيا.
  - للحزمة المدمجة (Cherry MX Black وBlue Clicky وClick Classic وSoft Click): تُزال من القوائم فقط، ويمكن استعادتها.
  - `Cancel`: لا يحدث شيء. إن حذفت الحزمة المفعّلة يختار البرنامج أول حزمة متاحة من النوع نفسه، أو لا شيء إن لم يبق.
- **زر `Restore built-in sounds`**: يظهر فقط بعد حذف حزمة مدمجة. يعيد كل الحزم المدمجة المحذوفة.
- **زر `+ Add keyboard sound`**: يفتح نافذة اختيار ملفات. اختر ملف صوت أو فيديو، واحدا أو أكثر.
  - يؤخذ الصوت فقط (الصورة تُهمل). يُستخدم أول 3 ثوان.
  - كل ملف يصير حزمة لوحة مفاتيح باسم الملف. **كل زر يُصدر الصوت نفسه.**
  - تتفعّل الحزمة الجديدة فورا.
  - إن لم يُقرأ الملف تظهر رسالة `Could not read "…" as audio`.
- **زر `+ Add mouse sound`**: مثل السابق، لكنها حزمة فأرة.
- **زر `Import V2 pack (select folder)`**: اختر مجلد حزمة جاهزة فيه `config.json` وملف الصوت المذكور داخله.
  - يقبل صيغة V2 من نوع `single` فقط.
  - الأخطاء: `config.json not found` أو `audio file missing` أو `Only V2 "single" packs supported`.
  - بعد النجاح تُضاف الحزمة وتُحفظ.

## 10. صفحة Customize

### مربعات المظاهر (Theme)
11 مظهرا. كل مربع فيه شريط ألوان صغير يعرض شكله. النقر على مربع يغيّر ألوان البرنامج كله فورا، والمحدد له إطار ملوّن. **المظهر نفسه يحدد إن كان فاتحا أم داكنا**، فلا يوجد مفتاح منفصل للوضع الفاتح.

- داكنة: `Classic Indigo` و `Dark Synthwave` و `Forest Green` و `Ocean Blue` و `Sunset Glow` و `Amethyst` و `Cyber Neon` و `Graphite`.
- فاتحة: `Minimalist White` و `Soft Rose` و `Fresh Mint`.

### شريط `Component opacity` (15 إلى 100%)
- يتحكم بشفافية البطاقات والأزرار والشريط السفلي. 100% = معتمة. أقل = تظهر الخلفية من خلفها.
- كلما قلّت الشفافية تزيد ضبابية الخلفية خلف العناصر تلقائيا، حتى يبقى النص مقروءا.
- يتحرك فورا بدون تقطيع. يُحفظ عند الإفلات. الحد الأدنى 15% حتى لا يختفي النص.

### شريط `Background image` (0 إلى 100%)
- يتحكم بوضوح **صورة الخلفية نفسها**. 100% = واضحة. أقل = تبهت الصورة ويبرز البرنامج. عند 0% تختفي الصورة.
- يحتاج صورة خلفية مختارة ليظهر تأثيره.

### قسم `Background images`
- **مربع `None`**: يزيل الخلفية.
- **مربعات الصور**: كل صورة رفعتها. النقر على واحدة يجعلها الخلفية فورا (الإطار الملوّن يدل عليها).
- **زر `✕` على الصورة**: نافذة تحذير ثم حذف الصورة نهائيا من البرنامج. إن كانت مفعّلة تُزال الخلفية.
- **زر `+ Add background image`**: اختر صورة أو أكثر. تُنسخ إلى مجلد البرنامج وتُفعَّل آخر صورة.

## 11. صفحة Mood (أصوات الخلفية)

- **القائمة المنسدلة**: اختر صوتا: `Rain` أو `Ocean waves` أو `Fireplace` أو `Café murmur`، وبعدها أصواتك. تبدأ تلقائيا إن كان مشغّلا.
- **شريط الصوت (0 إلى 100%، وحتى 200% بعد تفعيل خيار الإعدادات)**: علو صوت الخلفية. فوق 100% يصير أصفر وهو تضخيم حقيقي. (إن فشل التحميل المتقدم لملف يعمل بوضع مباشر بحد أقصى 100% ويكتب السجل بذلك.)
- **زر `▶ / ❚❚`**: تشغيل وإيقاف مؤقت. الصوت يتكرر بلا نهاية.
- **زر `+ Add sound or video`**: أضف أي ملف صوت أو فيديو بأي حجم ومدة. تُؤخذ الصوتيات فقط. يُنسخ الملف إلى مجلد البرنامج، فلا يتأثر إن حذفت الأصلي.
- **قائمة أصواتك وبجانب كل واحد `✕`**: نافذة تحذير ثم حذف الملف من البرنامج. إن كان يعمل يرجع إلى `Rain`.

## 12. صفحة Settings

### `Language · اللغة` — زرّا `English` و `العربية`
- `العربية`: تتحول كل نصوص البرنامج للعربية **ويصير اتجاه الواجهة كله من اليمين إلى اليسار** (الأزرار والقوائم والشريط السفلي). شرح Help يتحول للعربية أيضا.
- `English`: يرجع كل شيء للإنجليزية ومن اليسار إلى اليمين.
- يُحفظ الاختيار. أسماء الحزم والملفات التي تكتبها أنت تبقى كما هي. سجل التشخيص يبقى بالإنجليزية.

### زر `❓ Help · شرح البرنامج`
يفتح صفحة الشرح داخل البرنامج. في أعلاها:
- `← Back` أو `رجوع`: يرجع إلى Settings.
- `عربي` و `English`: يبدل لغة الشرح. تُحفظ.

### `Output device`
- قائمة منسدلة بأجهزة إخراج الصوت. اختيار جهاز يحوّل الصوت إليه **فورا بدون إعادة تشغيل**، ويشمل صوت الخلفية.
- `System default`: جهاز النظام الافتراضي.
- عند فصل الجهاز المختار يرجع الصوت للافتراضي ويكتب السجل، وعند إعادة توصيله يعود إليه.

### `Allow volume above 100% (up to 200%)`
- **مطفأ افتراضيا.** مطفأ: أقصى صوت 100% في لوحة المفاتيح والفأرة وMood. مفعّل: تصل الأشرطة إلى 200%.
- عند إطفائه بعد أن كنت فوق 100% تنزل الأشرطة إلى 100% تلقائيا.

### `Use newly added sounds automatically`
- **مطفأ افتراضيا.** مطفأ: الصوت الذي تضيفه بـ `+ Add keyboard sound` أو `+ Add mouse sound` يبقى في القائمة ولا يُفعَّل حتى تختاره أنت. مفعّل: يصير هو المستخدم فورا.

### `Keep window on top of other apps`
- مضاء: النافذة تبقى فوق كل البرامج ولا تختفي خلفها.
- مطفأ: تتصرف كنافذة عادية.
- يُحفظ ويُطبق عند كل تشغيل.

### `Keyboard random pitch` و `Mouse random pitch`
- مضاء: كل ضغطة تُصدر الصوت بحدة مختلفة قليلا (أعلى أو أدنى) فلا يتكرر الصوت نفسه.
- مطفأ: الصوت ثابت.
- مفتاح لكل جهاز.

### شريط `Pitch variation` (5 إلى 50%)
- مقدار التغيير في الحدة. 5% خفيف جدا، 50% واضح جدا. الافتراضي 20%.
- لا يؤثر إن كان المفتاحان مطفأين.

### `Debug log`
- **صندوق السجل**: أحداث البرنامج بالتوقيت (بدء المحرك، تغيير الجهاز، إضافة حزمة، الأخطاء). السطر الأول المهم: `bridge: ok`. إن ظهر `bridge: MISSING` فالأزرار العلوية لن تعمل.
- **خانة `Verbose`**: عند التفعيل يُكتب سطر لكل ضغطة: اسم الزر والصوت المستخدم وزمن الاستجابة. للفحص فقط. مطفأة = أحداث النظام فقط.
- **زر `Export`**: يحفظ السجل في ملف نصي اسمه `mechvibesdx-log.txt` (قد تظهر نافذة حفظ أو يذهب إلى مجلد التنزيلات).

## 13. القوائم المنسدلة (في كل البرنامج)

1. انقر على البطاقة: تفتح القائمة تحتها.
2. انقر على عنصر: يُختار وتُغلق القائمة.
3. انقر خارجها أو على بطاقة أخرى: تُغلق.
4. الخيار الحالي بلون التمييز.

## 14. ما لم يُنفّذ (بصراحة)

- التحديث التلقائي.
- تحويل حزم V1 إلى V2.
- تصفية إدخال كل جهاز على حدة (تحتاج واجهة نظام أعمق).
- إرسال إحصائيات مجهولة (حذفتها).
- محرر حزم حقيقي (الزر `Open` ينقلك للصفحة فقط).
- لم أستطع تجربة التطبيق داخل Electron بنفسي. أبلغني بأي خلل مع نص السجل أو صورة.

## 15. حل المشاكل

| المشكلة | الحل |
|---|---|
| لا صوت إطلاقا | افحص `Enable all sounds` ومكبرات كل جهاز (🔊) والأصوات في Windows |
| الأزرار العلوية لا تعمل | افتح `Settings`، انظر إلى `bridge:` في السجل، وأرسل نافذة الخطأ |
| لا يعمل إلا والنافذة نشطة | السجل يقول `window-only mode`: مكتبة `uiohook-napi` لم تُثبّت. شغّل `run.bat` ثانية |
| لا أرى الأيقونة بعد الإخفاء | انظر داخل السهم `^` بجانب الساعة واسحبها خارجه |
| الصوت متأخر | السماعات اللاسلكية ترفع التأخير. جرب سلكية. وانظر رقم `Latency` |
| تحذير `install-scripts` في الطرفية | طبيعي، لا يضر |
| فشل البناء بخطأ `Visual Studio` أو `node-gyp` | `package.json` الحالي يمنع إعادة بناء المكتبات (`npmRebuild: false`) لأنها تأتي جاهزة. لا تحتاج Visual Studio |
